# UNIFICATO — Stochastic Valuation of Barrick Mining

Publication-facing code, data notes and reproducibility material for the
Starting Finance Club PoliTo Research project **UNIFICATO**.

The project joins the mathematical, econometric, numerical and corporate
finance work developed by the eight Barrick Gold research teams into one
autonomous pipeline. It generates the analytical figures used by the unified
thesis and a conditional stochastic DCF for Barrick Mining Corporation.

> Educational and research material only. The valuation outputs are model
> sensitivities, not fair values, target prices or investment recommendations.

## Research architecture

The pipeline keeps four evidence domains explicit and separate:

- current licensed LSE market and option inputs;
- current public Barrick operating facts;
- Team 4 production and cost forecasts from 2026 Q3 onward;
- frozen legacy aggregates used only for historical validation.

Team 4 supplies the operating mechanics and forecast continuation. Its legacy
NSS curve, implied-volatility inversion, GBM gold paths and illustrative
stochastic EBITDA valuation are not used in the unified price or valuation
layers. Gold paths are generated by the Team 8 Black–Scholes, Heston,
Bates–Poisson and Full Bates–Hawkes engines.

The pipeline fits Nelson–Siegel–Svensson to the latest common-date LSE Treasury
cross-section and uses that curve both for option calibration rates and for
integral-preserving quarterly valuation forwards.

## Setup

Python 3.11 or newer is required.

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -e ".[test]"
```

`LSE_API_KEY` is required only to acquire a new licensed snapshot. Never
commit or print the key. The versioned local snapshots support offline replay.

## Reproduce the figures

Verify the public Barrick inputs when network access is available:

```bash
python tools/fetch_barrick_operating_sources.py
```

Generate and audit every analytical image, then promote accepted PNG files to
the adjacent Overleaf workspace:

```bash
python run_all_thesis_figures.py \
  --run-id <fresh-run-id> \
  --market-run-id <market-run-id> \
  --empirical-data-run-id <empirical-data-run-id> \
  --promote-overleaf
```

Run the complete offline test suite:

```bash
python -m pytest tests -q
```

For a handoff-oriented structural audit, run:

```bash
python main.py status
python main.py test -q
```

The notebook intentionally delegates to the same `UnifiedWorkflow` class and
does not duplicate numerical implementation.

pass and all 47 analytical article images pass the provenance audit.

## Valuation assumptions

The executed DCF assumptions are editable in
`config/provisional_valuation_20260827_team4_separated.json`. The multi-model
contract is in `config/multimodel_valuation_20260827_team4_separated.json`.
Generated CSV and JSON sidecars document the exact growth, ROIC, reinvestment,
WACC and terminal-value paths used in each run.

The four gold engines share:

- 8,192 valuation scenarios and aligned model seeds;
- one stochastic WACC shock matrix, reused across engines;
- one operating and equity-bridge methodology;
- Barrick's Q2 2026 average realised gold price of USD 4,417/oz as a level
  anchor, not as a spot quote or physical-price forecast.

Q1 and Q2 2026 production and Cost of Sales are Barrick actuals; Team 4
forecasts begin at Q3. Corporate bridge placeholders and the share-count proxy
remain unresolved and are labelled as provisional.

## Current-rate note

The 24 July 2026 NSS fit uses 11 synchronous LSE Treasury tenors. US10Y is not
available on that date: four delayed API retries and the live LSE catalogue
show 1 July 2026 as the provider's latest observation. The pipeline excludes
that stale node instead of mixing dates. The par-yield-derived curve is a
reproducible proxy, not a bootstrapped zero-coupon curve.

## Data and provenance

- Raw licensed LSE rows stay outside version control.
- Public Barrick inputs are source-manifested and hash-checked.
- Every analytical PNG must match a generated branch output byte for byte.
- Standalone Team 1–8 article images are never copied into this project as
  substitutes for missing generators.
- Caches, local environments, logs and review-only build artifacts are excluded
  from publication.
