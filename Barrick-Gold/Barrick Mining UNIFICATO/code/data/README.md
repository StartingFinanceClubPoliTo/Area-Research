# Data 📦

This folder separates inputs from code and generated presentation assets.

- `raw/lse_local/` contains licensed local-only inputs and is Git-ignored.
- `processed/` contains redistribution-safe inputs accepted by the current contracts.
- `manifests/` records provenance, hashes, dates and authoritative run pointers.

Do not copy row-level licensed data into notebooks, figures or publication packages.
