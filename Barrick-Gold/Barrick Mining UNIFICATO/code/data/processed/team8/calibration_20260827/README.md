# Team 8 calibration snapshot — 27 August 2026

This directory is the stable, redistribution-safe calibration dependency used
when the multi-model valuation configuration is executed directly.

The JSON files were generated by `tools/build_team8_thesis_figures.py` from the
local licensed LSE snapshot and copied from the accepted autonomous V17 run.
They contain fitted parameters and aggregate metadata only; no row-level LSE
option or Treasury data are included.

During a fresh `run_all_thesis_figures.py` execution, the refactored runner
replaces these fallback paths in memory with the calibration generated inside
the new run. This prevents a new run from depending on an older output folder
while keeping direct configuration-based tests reproducible offline.
