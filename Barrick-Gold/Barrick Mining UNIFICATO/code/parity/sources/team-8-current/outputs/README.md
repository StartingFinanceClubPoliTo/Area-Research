# Local generated outputs 📊

Calibration checkpoints, manifests, sampling reports, and rolling out-of-sample results are written here. Generated runs are ignored by Git by default; only this documentation and the directory placeholder are publication-facing.

A final calibration should save each model result immediately and retain enough metadata to reproduce the date, source surface, sampling strategy, profile, objective, and seed. Promote only reviewed aggregate figures or tables to `img/diagnostics_ibkr/`.

## Versioned file

| File | Role |
| --- | --- |
| `.gitkeep` | Preserves the local output destination while generated run contents remain ignored. |
