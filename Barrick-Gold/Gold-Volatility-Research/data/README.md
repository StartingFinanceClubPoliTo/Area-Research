# Data 📁

Input and processed datasets for the gold, silver, and macro-financial driver analysis.

## 📄 Folders

| Folder | Role |
| --- | --- |
| `raw/` | Raw Yahoo Finance downloads and intermediate level files. |
| `processed/` | Cleaned asset levels and return datasets used by the analysis scripts. |

## 🧪 Notes

The raw data are sourced from Yahoo Finance and can change if the provider revises historical observations. Use the root README for the full reproduction workflow.
