# Outputs 📊

Generated figures and tables for the gold, silver, and macro-financial driver analysis.

## 📄 Contents

This folder contains descriptive statistics, correlation outputs, rolling-correlation figures, regression tables, quality-check plots, and stylized-fact outputs generated by the scripts in `src/`.

## 🔁 Regeneration

From the project root:

```bash
python src/07_main.py
```

Generated files can change if upstream market data or model settings are updated.
