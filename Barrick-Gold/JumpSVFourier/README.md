# Beyond Black-Scholes Synthetic Examples

| Field | Value |
| --- | --- |
| Project | [Barrick Gold](../) |
| Article | 7 |
| Authors | Davide Sisto, Matteo Armando |

This folder provides reproducible synthetic examples for the Starting Finance Club PoliTo Research article on jump processes, stochastic volatility, Fourier methods, and Hawkes dynamics.

## Purpose

The examples connect the theoretical discussion to small simulated illustrations. They do not calibrate market data and they are not intended as an option-pricing benchmark.

## Structure

| Path | Role |
| --- | --- |
| `1 Simulations/simulate_examples.py` | Generates synthetic data and article figures. |
| `1 Simulations/img/` | Article-ready figure files generated by the script. |
| `1 Simulations/output/` | CSV files with the simulated paths and variance examples. |
| `requirements.txt` | Minimal Python dependencies for the simulation script. |

## Setup

Create a Python environment and install:

```bash
pip install -r requirements.txt
```

## Run

From this folder:

```bash
python "1 Simulations/simulate_examples.py"
```

## Outputs

| Output | Description |
| --- | --- |
| `1 Simulations/img/jump_diffusion_paths.png` | Synthetic jump-diffusion paths used as article figures. |
| `1 Simulations/img/stochastic_variance_examples.png` | Synthetic stochastic-variance illustrations. |
| `1 Simulations/output/jump_diffusion_paths.csv` | Simulated jump-diffusion path data. |
| `1 Simulations/output/stochastic_variance_examples.csv` | Simulated stochastic-variance path data. |

## Reproducibility Notes

- The script fixes the random seed and documents parameters near the top of the file.
- Paths are synthetic and are meant to visualize mechanisms discussed in the article.
- The examples are educational research material and do not provide investment advice.
