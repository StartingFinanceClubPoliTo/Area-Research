# Source Package

This folder contains the reusable Python package for the Monte Carlo risk article.

## Key Files

- `monte_carlo_risk/random_generators.py`: pseudo-random generation, distribution transforms, multivariate normal sampling, and diagnostics.
- `monte_carlo_risk/stochastic_processes.py`: GBM and jump-diffusion simulators.
- `monte_carlo_risk/option_pricing.py`: Black-Scholes formulas, Monte Carlo option pricing, Asian options, quasi-Monte Carlo, and barrier-option examples.
- `monte_carlo_risk/variance_reduction.py`: control variates, antithetic variates, stratified sampling, and importance sampling.
- `monte_carlo_risk/returns.py`: Gaussian-mixture returns, empirical inverse CDF mapping, VaR, CVaR, and terminal wealth utilities.

Use the root README for setup and execution commands.
