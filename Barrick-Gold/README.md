# Barrick Gold

This project collects research material related to Barrick Gold.

## Articles

- [A Component-Driven Methodology for EBITDA Forecasting in Gold Mining](./Component-Driven-EBITDA-Barrick/) - code and reproducibility material for the EBITDA forecasting article.
- [OLS To Dynamic Correlations](./OLS-Dynamic-Corr/) - reserved Team 2 article folder; the current package records that no executable code was provided.
- [Monte Carlo Methods and Portfolio Simulation](./Monte-Carlo-Risk/) - Article 4 code companion for Monte Carlo theory, convergence diagnostics, option-pricing examples, variance reduction, and portfolio risk simulation.
- [Beyond Black-Scholes Synthetic Examples](./JumpSVFourier/) - reproducible synthetic figures and data examples for the Team 7 theory article.
