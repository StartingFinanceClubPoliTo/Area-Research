# Three-Stage DCF with Simulated Data 🧮

This repository supports the Starting Finance Club PoliTo Research article on three-stage discounted cash flow valuation.

## 👥 Authors

- Federico Vesco
- Lorenzo Pietra
- Bader Moussaif

## 🎯 Purpose

The code demonstrates how a three-stage DCF model works using fully simulated data. It is not a valuation of Barrick Gold and does not produce a share price, target price, or investment recommendation.

## Published Article

The related Starting Finance Club PoliTo publication is available here: [Three-Stage DCF with Simulated Data](https://sfclubpolito.it/pdf-viewer.html?file=Pubblicazioni%2FThree-Stage%20DCF%20with%20Simulated%20Data.pdf&lang=it).

## 🗂️ Structure

| Path | Role |
| --- | --- |
| `src/generate_three_stage_dcf.py` | Complete Python simulation and figure-generation script. |
| `img/` | Figures generated by the script and used in the article. |
| `output/` | CSV summaries generated by the script. |
| `requirements.txt` | Minimal Python dependencies. |

## ⚙️ Setup

Create a local virtual environment and install the dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## ▶️ Run

From this folder, run:

```powershell
.\.venv\Scripts\python.exe src\generate_three_stage_dcf.py
```

The script writes figures to `img/` and CSV summaries to `output/`.

## 📊 Outputs

| Output | Description |
| --- | --- |
| `img/mc_dcf_results.png` | Base-case simulated DCF output. |
| `img/mc_scenarios.png` | Conservative, base, and expansion scenario comparison. |
| `output/base_summary.csv` | Base-case distribution statistics. |
| `output/scenario_summary.csv` | Scenario-level statistics. |
| `output/sensitivity.csv` | Rank-correlation sensitivity table. |

## 🧪 Reproducibility Notes

All model inputs are synthetic and defined in the `ModelParams` dataclass. The random seed is fixed by default, so the figures and tables can be regenerated exactly unless assumptions are changed.
