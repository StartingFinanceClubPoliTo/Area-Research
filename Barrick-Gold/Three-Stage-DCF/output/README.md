# Outputs 📊

CSV summaries generated by `../src/generate_three_stage_dcf.py` for the Three-Stage DCF with Simulated Data companion.

## 📄 Files

| File | Description |
| --- | --- |
| `base_summary.csv` | Base-case DCF distribution statistics. |
| `scenario_summary.csv` | Scenario-level valuation-distribution statistics. |
| `sensitivity.csv` | Rank-correlation sensitivity table for simulated drivers. |

These files make the article figures and summary statistics inspectable. Use the project root README for publication context and citation.
