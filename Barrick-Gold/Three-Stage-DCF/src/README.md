# Source Code 🧩

This folder contains the executable Python script for the Three-Stage DCF article companion.

## 📄 Files

| File | Role |
| --- | --- |
| `generate_three_stage_dcf.py` | Defines synthetic assumptions, runs Monte Carlo scenarios, exports charts, and writes CSV summaries. |

## ▶️ Run

Run the script from the project root so relative output paths remain stable:

```powershell
.\.venv\Scripts\python.exe src\generate_three_stage_dcf.py
```

Use the root README for environment setup and interpretation notes.
