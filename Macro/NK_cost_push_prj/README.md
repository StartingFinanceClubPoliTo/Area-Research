# New Keynesian Cost-Push Shock Project

This project simulates impulse responses in a linear New Keynesian model after a cost-push shock. It is designed as supporting code for a macroeconomic research article on how the intensity of monetary policy affects inflation and output-gap dynamics.

## Files

| File | Role |
| --- | --- |
| `nk_costpush_three_regimes.mod` | Dynare model with the New Keynesian IS curve, Phillips curve, Taylor rule, and persistent cost-push shock. |
| `run_nk_irfs.m` | MATLAB runner that executes Dynare, extracts IRFs, creates the summary table, plots the three regimes, and saves outputs. |
| `Outputs/nk_irf_summary_table.csv` | Summary statistics for peak inflation, output-gap loss, peak nominal rate, and cumulative output loss. |
| `Outputs/nk_irfs_three_regimes.png` | Raster version of the IRF chart. |
| `Outputs/nk_irfs_three_regimes.pdf` | Vector version of the IRF chart. |
| `Outputs/nk_irfs_results.mat` | MATLAB results file with the plotted IRF series. |

## Model

The `.mod` file defines three versions of the same model, each with a different inflation coefficient in the Taylor rule:

| Regime | Taylor-rule inflation coefficient |
| --- | ---: |
| Accommodative | `phi_pi = 1.10` |
| Benchmark | `phi_pi = 1.50` |
| Aggressive | `phi_pi = 2.00` |

Other key calibration choices:

- discount factor `beta = 0.99`;
- intertemporal elasticity parameter `sigma = 1`;
- labor-supply parameter `varphi = 1`;
- Calvo parameter `theta = 0.75`;
- cost-push shock persistence `rho_u = 0.50`;
- shock standard error `0.01`;
- Dynare simulation horizon `irf = 40`.

The runner plots the first 10 quarters after the shock and reports the response in percentage points.

## How To Run

Requirements:

- MATLAB;
- Dynare installed and available on the MATLAB path.

From MATLAB:

```matlab
cd Macro/NK_cost_push_prj
run_nk_irfs
```

The script creates `Outputs/` if it is missing and writes:

- `nk_irf_summary_table.csv`;
- `nk_irfs_three_regimes.png`;
- `nk_irfs_three_regimes.pdf`;
- `nk_irfs_results.mat`.

## Interpretation

The model illustrates the trade-off generated by a cost-push shock. A more aggressive inflation response lowers the peak inflation response but increases the output-gap loss. A more accommodative response cushions output more, at the cost of a larger inflation response.

## Version-Control Notes

Curated outputs in `Outputs/` are part of the reproducibility material. Dynare-generated temporary files, local logs, and MATLAB autosave files are ignored through `.gitignore`.
