# Market Making Simulation: Naive vs Avellaneda-Stoikov 🎥

📄 Article PDF: https://sfclubpolito.it/pdf-viewer.html?file=Pubblicazioni%2FHigh-Frequency%20Market%20Making%20under%20Avellaneda-Stoikov.pdf&lang=it

This folder contains reproducibility material for the first article in the Stoikov-Avellonada project. The notebook builds a cinematic simulation of the Avellaneda-Stoikov optimal market-making model, combining a 3D surface of the optimal bid spread with a four-panel trading simulation.

## 👥 Authors

- Niccolò Soriano
- Salvatore Messina

## 🎯 Purpose

The notebook visualizes inventory-aware market making and compares model-driven quoting behavior with a naive simulation baseline.

## ✨ What It Shows

- Optimal quoting surface as a function of time and inventory.
- Stylized mid-price path with bid and ask quotes generated by the model.
- Inventory dynamics during the simulation.
- Cash and PnL tracking across the rendered scenario.
- Video rendering pipeline with frame generation and MP4 compilation.

## 🗂️ Structure

| File | Role |
| --- | --- |
| `codice_articoloSF.ipynb` | End-to-end notebook containing the complete pipeline and explanatory implementation notes. |

## ⚙️ Setup

Python 3.10 or newer is recommended.

```bash
pip install numpy matplotlib imageio imageio-ffmpeg
```

The notebook uses only local simulation logic and does not require external market data.

## ▶️ Run

1. Open `codice_articoloSF.ipynb`.
2. Run the complete pipeline cell, or follow the explanatory section step by step.
3. The script renders frames in `temp_avellaneda_frames/`.
4. The final video is exported as `Avellaneda_Stoikov_Output.mp4`.
5. Execution logs are written to `avellaneda_pipeline.log`.

## 🧪 Reproducibility Notes

- The simulation is configured for 1920x1080 output at 30 FPS.
- The default duration is 13 seconds, with a short final hold.
- Rendering uses Python multiprocessing through `Pool`; adjust `CONFIG["N_WORKERS"]` if needed.
- Matplotlib runs with the `Agg` backend, so the notebook can render frames without opening GUI windows.
