# Images 🖼️

Article-facing figures for the Rough Volatility and End-of-Day Inventory Control companion folder.

| Path | Role |
| --- | --- |
| `article_figures/` | Static PNG files referenced by the LaTeX article. |
| `2/` | HJB surface and simulation figures generated by `src/solve_rough_hjb.py`. |

To refresh the static diagnostic figures, run `python src/generate_article_figures.py --output output/generated_figures` from the article folder root. To refresh HJB figures, run `python src/solve_rough_hjb.py`.
