# Outputs 📊

Generated numerical outputs for the Rough Volatility and End-of-Day Inventory Control companion folder.

| Path | Role |
| --- | --- |
| `hjb_summary.json` | Preserved HJB summary from the article delivery folder. |
| `generated_figures/` | Regenerated static figures from `src/generate_article_figures.py`; covariance profiles use mean absolute error along constant-lag diagonals. |

The root-level `hjb_summary.json` is regenerated by `src/solve_rough_hjb.py`; keep this folder for curated outputs that should remain easy to inspect without rerunning the full workflow.
